## Source-of-truth policy

- **Playable origins / runtime display / IDs / flags / scenes**: runtime/code wins (`originProfiles.ts`, `pilot.snapshot.json`, StoryDetective runtime files).
- **Biography, motives, secrets, factional meaning**: lore/design files win only when tied to a runtime ID and not contradicting shipped display identity.
- **Detectiv-only names/aliases** are reference material, not automatic runtime truth. Known drift remains visible below instead of being silently erased.
- Existing identity ledger: [`docs/CASE01_CANON_IDENTITY.md`](CASE01_CANON_IDENTITY.md).

## High-priority drift notes

- `Arthur Vance` must be reserved for the **Journalist** origin; detective-origin canon is `Matthias Adler` / `inspector`.
- `Lotte Weber` resolves to `npc_weber_dispatcher`; `operator` / `Lotte Fischer` are legacy reference metadata only.
- Year/era split is resolved for supported Freiburg / Case01: `1900` is operational canon; `1905` remains legacy/prototype/display drift until a separate ADR promotes it. See [`docs/adr/0001-freiburg-1900-operational-canon.md`](adr/0001-freiburg-1900-operational-canon.md).
